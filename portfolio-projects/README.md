# Portfólio de Projetos | Tecnologia, Dados, Finanças e Beauty Tech

Este diretório reúne oito projetos estratégicos para demonstrar competências em engenharia de software, dados, analytics, produto digital, growth e negócios.

Os projetos conectam minha experiência em Coordenação de Marketing e Growth com minha formação em Engenharia de Computação e Análise e Desenvolvimento de Sistemas.

> Comece pelo [Guia Mestre de Desenvolvimento](./DEVELOPMENT-GUIDE.md). Ele explica a ordem de execução, o padrão de qualidade e quando um projeto pode ser considerado pronto para currículo.

## Objetivo do portfólio

- Demonstrar domínio de lógica, dados, APIs, dashboards e produto digital.
- Criar evidências práticas para bancos, fintechs, consultorias, empresas de tecnologia e beauty tech.
- Unir visão técnica com experiência real em growth, marketing analytics, gestão de projetos e coordenação de equipes multidisciplinares.
- Mostrar capacidade de entender problemas, tomar decisões, implementar, testar e comunicar resultados.

## Padrão de documentação

Cada pasta contém:

- `README.md`: visão rápida do projeto para recrutadores.
- `DOCUMENTATION.md`: arquitetura, modelo de dados, requisitos, passo a passo, testes, critérios de aceite, commits e evoluções.

Conforme o desenvolvimento avançar, cada projeto também deverá conter código, dados simulados, testes, diagramas, imagens da demonstração e pipeline de CI.

## Status

A documentação detalhada de implementação foi estruturada. Os projetos permanecem em desenvolvimento e só devem ser apresentados como concluídos quando cumprirem a Definition of Done registrada no Guia Mestre.
